# Sephora Product Review Dataset – Machine Learning Approach

## 📌 Project Overview

This project presents an end-to-end **machine learning analysis** of the **Sephora Product & Skincare Review Dataset**, focusing on how customer reviews and product attributes can be transformed into actionable insights.

Rather than treating reviews as simple feedback, this project leverages data-driven techniques to:

* Understand what drives **product pricing**
* Reveal hidden patterns in **customer satisfaction**
* Translate customer preferences into a **recommendation system**

By combining exploratory analysis with multiple machine learning paradigms, this project demonstrates how real-world consumer data can support strategic decisions in pricing, marketing, and product positioning.

---

## 🎯 Objectives

1. Conduct exploratory data analysis to understand patterns and characteristics of Sephora product reviews.
2. Build a regression model to predict **product pricing** based on relevant features.
3. Group customers according to satisfaction levels using clustering techniques.
4. Develop a classification model as the foundation of a **product recommendation system**.
